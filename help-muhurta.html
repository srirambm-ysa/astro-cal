What This Finder Does

This standalone tool finds Shubh dates for 140 activities — purchase, griha pravesha, travel, ceremonies — by scoring every day in the selected month against the classical rules of Muhurta Chintamani (Ch. 2–3). It uses the same engine as the calendar dashboard, but without loading the full Panchang month table.

Birth star (Janma Nakshatra) and month are shared with the calendar via local storage (astro-cal-birth / astro-cal-view). Set birth once in either page; both stay in sync.

All computation runs locally with the Swiss Ephemeris (WASM, Lahiri ayanamsa) — no server round-trip.

Step 1: Set Your Birth Data

Tap the persona pill (★ Set birth star) or open the birth card. Pick your Janma Nakshatra (27); Rashi auto-fills but is correctable for stars spanning two rashis. Place/lat/lon/tz can be filled via city search or manually. The finder shares this birth with the calendar dashboard.

Shared birth: Changing birth here updates the calendar's Avoid Days, Gochara, and Key Lunar Days immediately. The calendar's city quick-select (382 cities) writes the same keys.

Step 2: Select Domain → Activity → Sub-activity

Every muhurta is activity-specific — there is no blanket auspicious time. Use the three-level cascade:

  • Domain — broad category (e.g. Real Estate, Marriage, Vehicle)
  • Activity — type (e.g. Griha Pravesha, Vehicle Purchase)
  • Sub-activity / Task — exact task (e.g. New Home, Used Home)

Each task has its own Hard Blockers, preferred nakshatras/tithis, and functional group (Sthira/Chara/Mridu/Kshipra/Tikshna). The engine loads the correct rulebook automatically. Use 📋 Activity Catalog to browse all 140.

Quick Picks: Chips above the dropdowns set all three levels in one tap. + Save pins your current selection as a new chip (stored locally); × removes a custom chip. Chips wrap and scroll on mobile.

Step 3: Choose a Mode

Mode selects strictness. This replaces the old “Muhurta on the calendar” toggle — now you compute on demand via Compute Muhurta.

Full/Soft are impersonal (universal time quality only). Personal first qualifies as a Full slot (≥ 80), then applies Tara Bala (transit nakshatra vs birth, 2,4,6,8,9 favourable ✨ vs 3,5,7 bad ⚠️) and Chandra Bala (Moon house from janma rāśi, 1,3,6,7,10,11 favourable). Naidhana Tara or Ashtama Chandra (8th) hard-rejects even a Full slot.

Step 4: Compute & Read the Results

Controls

  • Month ◀ ▶ — navigate Gregorian month (IST). Changing month clears results (intent only; no auto-compute).
  • Compute Muhurta — scores every day of the shown month. Requires birth + domain/activity/mode. Heavy scan runs in a worker (falls back to main thread).
  • Clear — resets domain/activity and wipes table.
  • Source ⓘ — opens the classical verses governing the selected activity (modal, copy citation).

Muhurta Table

Shows only days that pass as Shubh for the selected activity+mode (Neutral not listed). Columns:

  • Date — e.g. Tue Sep 11 (with till 07:26 → Revati if the nakshatra changes intra-day)
  • Tara — position 1–9 vs birth (shown for reference in all modes)
  • Nakshatra — ruling lunar mansion that day
  • Verdict — Shubh score (≥ cutoff)

Below the table: Why others set aside: nakshatra — n days · tithi — n days… lay summary (a day can be set aside for multiple reasons). Footer: Shubh days this month for X · Month · Mode (2-4 expected).

Row Details (Tap a Shubh Day)

Tap any Shubh row to expand the accordion below the table:

  • Score 0–100 + verdict (REJECTED → EXCELLENT)
  • Tara / Chandra — Tara name + nature, and in Personal mode the Chandra house + bonus (+15 favourable / -10 unfavourable / 8th Ashtama blocked)
  • Tier breakdown — T1 Hard Blockers, T2 Primary (nakshatra/tithi), T3 Secondary (vara/karana), plus Passing lines
  • Override — if Sarvartha Siddhi / Siddha Yoga / Abhijit etc. downgraded a hit
  • Time window — validTill → nextStar when the nakshatra changes
  • Classical Foundation — the Muhurta Chintamani verses that fired that day (or the governing verses if none fired). Sanskrit, translation, applied logic, proof="confirmed" only.

Row selection toggles and is persisted (astro-cal-view.selected). The details stay open on month nav until you tap again.

Quick Picks & Presets

Chips above the dropdowns. Default 5 (Griha Pravesha, Vehicle Purchase, etc.) plus your customs. Clicking a chip sets Domain/Sub/Task and clears the table (you must press Compute again). The active chip highlights. Use Browse all to open the catalog.

Night Mode & Sharing

Moon icon toggles dark theme (synced with calendar via astro-cal-theme). Birth, month, and view mode are shared; the calendar's month table and this finder do not share computed results — each computes on demand.

Classical Sources

Every Hard Blocker (ASTA_GURU / ASTA_SHUKRA / TUESDAY / SANKRANTI / VYATIPATA / VAIDHRITI / BHADRA_MRITYU), nakshatra preference, and override is drawn from Muhurta Chintamani (Rama Daivagya). Tap Source (book icon) next to the activity name to see the exact chapter/verse and English rationale. All verses in reference/provenance_registry.json carry proof==="confirmed" — no fabricated citations.

Limitations

  • Personal aid, not a substitute for a qualified jyotishi.
  • Panchanga values vary by school, ayanamsa, location; classifications may differ from your family pundit's practice.
  • For dates that matter — consult a jyotishi and confirm against a trusted panchang.
  • Uses Lahiri ayanamsa and Swiss Ephemeris. Day = sunrise→sunrise at your location.
