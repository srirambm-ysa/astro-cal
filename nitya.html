4 · One Devi — PNG original vs WebP 128 (at 96 CSS px)

Rule of thumb: display size should be ≤ file native size. 128w file can display up to 128 CSS without blur; at 96 CSS it’s upsampled 0.75× (fine). 64w file at 96 CSS is stretched 1.5× (soft).

How to test

  • Use the slider in §2 — find the smallest display size you still find devotional/legible. Owner call: do we want delicate (48–64) or reverent hero (96–128)?
  • Switch Source between opt64 / opt128 / opt256 at same display size to see file-quality vs payload. opt128 is the budget pick.
  • On your phone (DPI 2–3×), a 48 CSS chip needs 96–128w file to stay crisp — that’s why 128w is the sweet spot.
  • When you’ve picked a size, note it (e.g. “hero 96, chips 48, detail 150 lazy”) — I’ll wire that exact mapping into rules/nitya_devis.json + app.js with srcset and ship only those WebPs.

Run locally: node serve.cjs → http://127.0.0.1:8124/nitya.html (or npm run build && npx wrangler dev —assets public — mock not included in public/ yet).
